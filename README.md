# LLM Test Machine

**Версия 1.0**

---

## О проекте

LLM Test Machine — это десктопное приложение для нагрузочного тестирования LLM-моделей. Программа отправляет множество параллельных запросов к API, отслеживает прогресс в реальном времени и сохраняет результаты в текстовый файл.

Приложение поддерживает работу с прокси-серверами, API-ключами и позволяет гибко настраивать параметры тестирования.

---

## Возможности

- Отправка параллельных запросов с контролем задержки
- Автоматическая ротация прокси-серверов
- Работа с любыми LLM-серверами (API и локальные)
- Отображение прогресса в реальном времени
- Отмена теста в любой момент
- Сохранение результатов в TXT файл
- Современный интерфейс с тёмной темой
- Работа с файлами промптов и прокси

## Как использовать

1. Введите URL вашего LLM-сервера.
2. Укажите количество запросов и время теста.
3. Загрузите файл с промптами (каждый вопрос на новой строке).
4. При необходимости загрузите файл с прокси (опционально).
5. Нажмите **"Начать тестирование"**.
6. Отслеживайте прогресс в реальном времени.
7. После завершения нажмите **"Скачать результаты"**.
